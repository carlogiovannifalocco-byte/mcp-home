        Connect to Alexa+ or any MCP client

        This endpoint is only reachable from this machine. Alexa+ needs a public HTTPS URL: deploy the server (see the README) and set PUBLIC_URL.

        Bearer
        green = read only (readOnlyHint), safe to call without asking
        1. Run npx @modelcontextprotocol/inspector
        2. Transport type Streamable HTTP, URL
        3. Add the header Authorization with value Bearer
        4. Connect, then List Tools and call weekly_briefing: it returns the sentence above.

        The MCP client demo talks to this endpoint the way Alexa+ would: initialize, tools/list and tools/call over Streamable HTTP, with the reply Alexa would speak and the time of each call.

        Alexa+ links the account with OAuth: deploy with PUBLIC_URL, set OAUTH_CLIENT_ID, OAUTH_CLIENT_SECRET and OAUTH_REDIRECT_URIS, and enter this household token on the consent page when linking (README, "Connect to Alexa+"). Everything Alexa adds shows up here within 30 seconds.
